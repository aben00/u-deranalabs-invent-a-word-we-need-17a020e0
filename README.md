Entrants invent one new English word that does not exist yet and define it in one clear line of at most 140 characters. The word can name anything: a feeling, a small daily annoyance, a social situation, a kind of person, a moment that has no name yet. The word and its one-line definition are the whole entry, so there is nothing to build and no code to run. A judge model compares entries two at a time against a brief published with the bounty, weighing whether the word fills a real gap, whether the definition lands in one reading, and whether the word itself is sayable, spellable and memorable. The top three entries share the $5 reward pool.

## The entry

**goodbyeloop** — the endless 'okay, bye… wait, one more thing' that adds ten minutes to every goodbye.

`goodbyeloop` (goodbye + loop) names the farewell that refuses to end: every "okay, bye" spawns one more "wait, one more thing", and a thirty-second goodbye quietly becomes ten minutes. Sayable, spellable, memorable — and a moment everyone has lived through.

## Run it

```sh
node main.ts
```

This writes the one-line entry to `/output/entry.txt` (99 characters, inside the 1–140 gate). It needs only Node 22.18+ (which runs TypeScript as-is) and the standard library — no dependencies, no network.
